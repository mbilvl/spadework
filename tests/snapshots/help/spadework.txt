Usage: spadework [OPTIONS] COMMAND [ARGS]...

  Evidence-first research for projects in discovery.

Options:
  --version           Print the version and exit.
  -C, --project PATH  Run as if started in PATH, like git -C.
  -q, --quiet         Print only results, warnings and errors.
  -v, --verbose       Print more, including tracebacks.
  --no-color          Disable colour. NO_COLOR is honoured too.
  --help              Show this message and exit.

Commands:
  init       Create a project from a playbook.
  check      Validate the project and print the plan.
  run        Run the pipeline.
  status     Show task states and the last run.
  verify     Check the quote of every source in the pack again.
  logs       Show session traces.
  doctor     Check the environment spadework runs in.
  playbooks  List or show the built-in and local playbooks.

  Examples:

    spadework init acme-fabrication
    spadework check -C acme-fabrication
    spadework playbooks list
